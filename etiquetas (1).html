Gerador de Etiquetas para OMB

Planilha → QR Code → Etiquetas Pimaco A4250 / A4350 (2 colunas × 5 linhas, 99 × 55,8 mm)
1. Planilha 2. Colunas 3. Diagramação 4. Gerar & Imprimir

📋 Esta plataforma foi construída para uso com folhas de etiqueta Pimaco modelo A4250 e A4350 (folha A4, 2 colunas × 5 linhas, etiquetas de 99 × 55,8 mm).

Antes de começar: preencha o modelo de planilha

Baixe o arquivo modelo abaixo, preencha com os dados dos atletas (Código, Unidade, Modalidade, Atleta, Cargo) e, em seguida, envie esse mesmo arquivo preenchido no campo logo abaixo.

⬇️ Baixar modelo de planilha (.xlsx)

1. Envie a planilha preenchida

Aceita .xlsx ou .xls. Os dados serão lidos direto pelas letras das colunas (A, B, C…), como na sua planilha.

Clique para escolher o arquivo
ou arraste o .xlsx aqui

Escolha a planilha (aba)

Este arquivo tem mais de uma planilha. Selecione qual delas contém os dados a usar.

2. Confira os dados e escolha as colunas

Pré-visualização da planilha (linhas e colunas reais). Marque se a primeira linha é cabeçalho.

Nomeie as colunas

Use o nome de cabeçalho detectado ou digite um nome para identificar colunas sem cabeçalho (ex.: "Unidade", "Atleta").

Esta coluna não aparecerá como texto na etiqueta — apenas o QR code será gerado a partir dela.

3. Diagrame a etiqueta

Arraste o QR code e os campos de texto para a posição que preferir dentro da etiqueta (99 × 55,8 mm). Clique em um campo para ajustar tamanho da fonte, negrito e alinhamento. Os valores mostrados são apenas um exemplo (primeira linha da planilha).

Propriedades

Clique em um campo na etiqueta para editá-lo.

Filtrar o que será impresso

Escolha a coluna (por exemplo, Unidade) e marque quais valores devem entrar na impressão. Desmarque o que não deseja imprimir.

Selecionar etiquetas individualmente

Ative para escolher, uma a uma, quais pessoas devem ter etiqueta impressa — útil para reimprimir só alguns nomes.

Ajuste fino da folha e impressão

Valores padrão calculados para a folha Pimaco A4250 (A4, 2 colunas × 5 linhas, etiqueta 99 × 55,8 mm). Imprima primeiro em papel comum e confira contra a folha de etiquetas antes de usar o adesivo — ajuste os valores abaixo se necessário.
